## Comandos exactos por tarea
- Verificación BETO (`F11-0`): `docker exec giragroup_pipeline python -c "import urllib.request; print(urllib.request.urlopen('http://127.0.0.1:8006/health').read().decode())"` + pruebas a `/infer`, `/indice`, `/embed`.
- Pre-respaldo (`F11-0`): `docker exec giragroup_db sh -c 'pg_dump -U "$POSTGRES_USER" -d "$POSTGRES_DB" -Fc' > backups/pre_f11_seguridad.dump`.
- Respaldo Pre-Defensa (`F11-3`):
  - `docker exec giragroup_db sh -c 'pg_dump -U "$POSTGRES_USER" -d "$POSTGRES_DB" --clean --if-exists' > backups/snapshot_pre_defensa.sql`
  - `docker exec giragroup_db sh -c 'pg_dump -U "$POSTGRES_USER" -d "$POSTGRES_DB" -Fc' > backups/snapshot_pre_defensa.dump`
- Restauración rápida en ~10 s (para mañana antes de la defensa):
  - `Get-Content backups\snapshot_pre_defensa.dump -Raw -Encoding Byte | docker exec -i giragroup_db sh -c 'pg_restore -U "$POSTGRES_USER" -d "$POSTGRES_DB" --clean --if-exists --no-owner'` (o vía `restaurar_semilla.bat`).
