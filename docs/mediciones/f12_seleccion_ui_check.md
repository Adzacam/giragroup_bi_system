# F12-2b — Verificación UI de Prioridad, Selección Múltiple y Revelación (`1280×800`)
- **Filtro Prioridad:** selector `Prioridad` (`Todas`, `Alta`, `Media`, `Baja`) operativo junto a `Área`.
- **Selección múltiple controlada:** barra con `Seleccionar página (20)`, `Justificación (opcional)`, `Confirmar seleccionados` y `Descartar seleccionados`, sin botón de inserción masiva a ciegas.
- **Bloqueo `< 30 %` (`muy_distinto`):** oculta los botones de acción en lote, deshabilita checkboxes de fila y muestra el aviso `Similitud < 30 %: revisión individual obligatoria (no se permiten acciones en bloque).`.
- **Corrección similitud y revelación:** `Similitud` muestra porcentaje real (p. ej. `46.8 %`, `31.4 %`, sin multiplicar ×100) y `Revelar nombre` / `Revelar con auditoría` descubren cédula, nombre en fuente, candidato sugerido, padrón y línea IOB2.
